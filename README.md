# IVT — Ivoire Vivrier Trading

Site statique (HTML / CSS / JS), aucune installation nécessaire.

- `index.html` — Accueil
- `boutique.html` — Boutique (catalogue)
- `prix.html` — Tendance prix du marché (variations + mercuriale)
- `methode.html` — Notre méthode (du champ au marché)
- `produit.html` — Fiche produit
- `panier.html` — Panier (commande via WhatsApp)
- `data/catalogue.js` — produits et prix
- `assets/` — styles, scripts, images

Publication : GitHub Pages → branche `main`, dossier racine (`/`).
