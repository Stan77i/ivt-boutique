IVT — NOMS DE FICHIERS ATTENDUS POUR LES PACKSHOTS
==================================================

Déposez ici une image par produit, au format PNG à FOND TRANSPARENT,
carrée (1000 × 1000 px recommandé), avec le nom exact ci-dessous.

Si vos photos ont un fond blanc, passez-les d'abord dans le détoureur :

    pip3 install --user Pillow
    python3 scripts/detourer.py <dossier-de-vos-photos> assets/img/produits

(le script nomme les fichiers de sortie comme les fichiers d'entrée :
 renommez donc vos photos avec les noms ci-dessous AVANT de lancer le script)
